# Checklist d'indexation SCT Africa

## Etat technique deja en place

- Site public disponible sur https://sct-africa.site/
- HTTPS actif
- robots.txt public : https://sct-africa.site/robots.txt
- sitemap.xml public : https://sct-africa.site/sitemap.xml
- Balises title, description et canonical presentes sur les pages principales

## Google Search Console

1. Ouvrir Google Search Console.
2. Ajouter la propriete du site : https://sct-africa.site/
3. Valider la propriete.
4. Ouvrir la section Sitemaps.
5. Soumettre : https://sct-africa.site/sitemap.xml
6. Ouvrir l'inspection d'URL.
7. Tester ces pages puis demander l'indexation :
   - https://sct-africa.site/
   - https://sct-africa.site/about/
   - https://sct-africa.site/contact/
   - https://sct-africa.site/devis/
   - https://sct-africa.site/missions/
   - https://sct-africa.site/engagements/
   - https://sct-africa.site/products-imprimantes/
   - https://sct-africa.site/products-accessoires/
   - https://sct-africa.site/products-scanners/

## Bing Webmaster Tools

1. Ouvrir Bing Webmaster Tools.
2. Ajouter le site : https://sct-africa.site/
3. Valider la propriete.
4. Soumettre le sitemap : https://sct-africa.site/sitemap.xml
5. Demander l'exploration des pages principales.

## Verification publique rapide

- Accueil : https://sct-africa.site/
- Robots : https://sct-africa.site/robots.txt
- Sitemap : https://sct-africa.site/sitemap.xml

## Delais normaux

- Apparition dans Google : quelques heures a quelques jours
- Apparition dans Bing : quelques heures a quelques jours
- Mise a jour complete des resultats : parfois 1 a 3 semaines

## Si Google n'indexe pas vite

- Verifier que la page repond bien en 200
- Verifier que robots.txt n'interdit rien
- Verifier que la page n'a pas de balise noindex
- Verifier que le contenu est accessible sans connexion
- Refaire une demande d'indexation dans Search Console
